# /mix

add your audio files here. `build.py`, `serve.py`, `rip.py`, and `buy.py` generate `tracks.json` by scanning the files in this directory.

supported formats: `.mp3`, `.m4a`, `.ogg`, `.flac`, `.wav`

## optional files
- `custom.css` - custom styles to override the default theme
- `custom.js` - custom scripts for additional functionality
- `album_art.jpg` - cover art for your mix (overrides the default in `/resources`)
- `icon.png` - home screen icon for your mix (overrides the default in `/resources`)
